# 办节点

**一个对话只服务一个节点**（`CONTEXT.md`「回合」，ADR-0008、ADR-0010）：出件、补事实、要求重出、最后一句确认或不适用，都在这个对话里；下一个节点开新对话。隔夜拍板是新对话、同一个名字。

前置：工作区就是会话当前目录，`图.json` 是它的身份标记（ADR-0007）。没有 `图.json` 就拒绝，告诉律师先在案件目录里开会话，还没起手就调用 skill "loo0ng-setup-case"。领域目录的绝对路径在工作区根的 `AGENTS.md` 里，凡要 `--domain` 的命令都从那里读。

本 skill 自己没有脚本，四件事都经别人的 CLI 落盘：图经 skill "loo0ng-graph"，归档与陈述经 skill "loo0ng-filing"，转换与门禁经 skill "loo0ng-to-docx"。

## 律师那句话 = 动作 + 节点 + 补充

| 律师说 | 去哪一节 |
| --- | --- |
| 「出一版 X」「X 重出一版」「按法院的意见改 X」 | [出一版](#出一版) |
| 「X 我自己写好了」「X 用我这份」 | [兜底登记](#兜底登记) |
| 「确认 X」「X 这份就这样，可以了」 | [拍板](#拍板) |
| 「X 不适用」「模块 Y 本案不办」 | [拍板](#拍板) |

补充可带「以第 n 版为底」「用某模板 / 某过往文书」与对内容的要求，照办即可，不改动作的判定。节点用图内唯一标题指认；律师说的名字与图里不完全一致时，找最接近的那个并在回显里写出你按哪个节点办的，别自己新建一个同义节点。

## 三条留痕规则

确认与不适用是律师专权，保护不在入口门上而在留痕与可逆上（ADR-0010）：

1. **原话原样存**。`--words` 里是律师那一句，一个字不改、不润色、不概括；`图视图.md` 显示的就是它。
2. **只在律师明确说出「确认」或「不适用」且指向本节点时落条目**。从「看起来没问题」「律师没提意见」推断出来的确认不落；律师问「这份行吗」不是确认；模型永不代律师拍板（ADR-0002）。拿不准就问一句，别先落再问。
3. **同一对话第二次「出一版」指向另一节点即拒绝**：告诉律师这个对话已经在办哪个节点，办完这个再开新对话办那个，并把下一句该打什么给他。同一节点重出不拒（那还是这一个回合）；拍板不限次数、也不受这条约束。

## 拍板

一句话即落，没有第二次确认，不先出示再问。

```
python <loo0ng-graph 的 scripts/graph.py> --domain <领域目录> confirm --node <节点标题> --words "<律师那句话>"
python <loo0ng-graph 的 scripts/graph.py> --domain <领域目录> not-applicable --node <节点标题> --words "<律师那句话>"
python <loo0ng-graph 的 scripts/graph.py> --domain <领域目录> not-applicable --module <模块标题> --words "<律师那句话>"
```

- **模块不适用**由引擎把该模块在领域图里的全部节点带进案件图、再逐个记一条不适用，模型不必先逐个 `add-node`。
- 引擎自己守的规则，拒了就把它的原话照实转告，别绕：已确认的节点不能不适用（要改就重出一版）；不适用是终态；只有已生成的节点能确认；模块里有已确认的节点时整个模块不适用被拒。
- 确认之后节点就完成了，这个对话到此为止，收尾按下面的三段写。
- 律师说「删掉 X」时答复是记不适用，节点永不删（ADR-0003）。

## 兜底登记

律师说「X 我自己写好了」：那份文书是他写的，**永不改动、不重转、不搬**（ADR-0002）。

1. 文件在收件箱里就先归档（调用 skill "loo0ng-filing"，成品文书归 `材料/`）；在工作区外就拷进 `材料/` 下，原件不动；已经在工作区里就原地登记。条目里记的相对路径就是它当前的位置。
2. 是 DOCX 就跑一次门禁（调用 skill "loo0ng-to-docx" 的 `gate.py`，**不带 `--deliver`**）。门禁**只披露不阻断**：不通过项照样写进审查报告，不因此拒绝登记、不改文书、不重转。不是 DOCX（`.md`、`.doc`、扫描件）就不跑门禁，报告里照实写未跑。
3. 按 [references/兜底件审查报告.md](references/兜底件审查报告.md) 写一份审查报告，落在 `文书/<节点标题>/<标题>-v{n}-审查报告.md`（`<标题>` 就是节点标题，`{n}` 是这个节点算上这一版的生成条目数）。每一版文书必有一份审查报告（`CONTEXT.md`「审查报告」）；律师那份文书留在他放的位置、报告落进这个节点的文书目录，两条相对路径都在条目里，条目才是文书的身份（ADR-0007）。起手时既有成品的登记同一个形状（skill "loo0ng-setup-case"）。
4. 追加生成条目，来源记律师：

   ```
   python <loo0ng-graph 的 scripts/graph.py> --domain <领域目录> generate --node <节点标题> \
       --doc <文书相对路径> --review <审查报告相对路径> --lawyer-written
   ```

登记只是已生成，**不是确认**：律师要确认，还得读过报告后再说一句（本对话里就可以）。

## 什么算一次生成

**一次生成 = 三件加一条条目**：文书、Markdown 源（兜底件可以没有）、审查报告，与图上那一条带着相对路径的生成条目，缺一即生成失败（`CONTEXT.md`「审查报告」）。工作台出的那版三件都落在 `文书/<节点标题>/`；兜底件的文书留在律师放的位置，报告仍落进那个目录。由此两条，本 skill 不在时两个 harness 会各走各的（#28）：

- **单跑转换与门禁不是一次生成**。律师只说「把这稿子转成 word」「这份 docx 检一下」时，产物留在临时位置或律师指的位置，**不落进 `文书/`**、不写审查报告、不动图；门禁本来就可以单独对任意 DOCX 跑。要它成为这个节点的一版，走本 skill 的[出一版](#出一版)或[兜底登记](#兜底登记)。
- **生成条目只有一条来路：本 skill**（ADR-0008「一类写入一条来路」，`draft` 与 `decide` 由 ADR-0010 并成本 skill）。参考 skill 被律师一句话够到之后只做转换、门禁、搬运、落档，不自行追加生成条目，也不自己补写审查报告。

## 出一版

顺序是死的，中间不停下来问：**归档 → 复制律师指的文件 → 惰性建节点 → 三样全无则只回缺什么 → 整读 → 写稿 → 转换 → 门禁 → 落盘 → 追加条目 → 回显**。

### 1. 开场归档

调用 skill "loo0ng-filing"：先 `archive.py list`，逐件判去向搬完，拿不准的留在收件箱并说一句为什么。收件箱空就不必回显这一步。

### 2. 复制律师指的文件

律师在对话里指的盘外文件都要落进工作区（ADR-0007），否则下一个对话看不到它：

- 本案的材料：拷进 `材料/`，原文件名不改。
- **别案的成品文书：不整份复制**。剔除案件内容（当事人、案号、日期、金额、地址）后作为空白模板存进 `模板/生成/`，再用它出件。把 A 案的成品带进 B 案是硬错。
- 律师在对话里给出的、盘上没有的事实：见下面的[生成不问缺事实](#生成不问缺事实)。

### 3. 惰性建节点

节点不在图里就由引擎按领域图带入（`add-node --module <模块> --title <标题>`，标题与领域图里某节点相同则连模块一并带入），不带同模块其他节点。领域图里也没有的，按律师说的标题新建，空白模板属性照他说的写。

### 4. 材料、指南、空白模板三样全无

这个节点手上一样能读的都没有（`材料/` 与 `材料/律师陈述/` 空、`指南/` 空、这个节点没有空白模板）时，**只回缺什么，不出件**：这不算一次生成失败，图一个字不动（ADR-0008）。回显里写清缺哪几样、律师可以怎么补（拷进收件箱、在对话里说一句事实、指一份模板），下一句仍是在这个对话里继续办这个节点。

### 5. 整读

不摘要、不抽样，整份读：`材料/` 全部（含 `材料/律师陈述/` 里现行的那些，未被任何文件指为取代目标的才是现行）、`指南/` 全部、这个节点的空白模板（`模板/官方/` 或 `模板/生成/`）、这个节点已有的过往文书（`文书/<节点标题>/`，「以第 n 版为底」就以那一版为底）。DOCX 读不动就用 skill "loo0ng-domain" 的 `docx-text` 打成纯文本。

一个对话只办一个节点、下一个对话重新读一遍，这是接受的代价（ADR-0008），别为省事跳过。

### 6. 写稿、转换、门禁、落盘

调用 skill "loo0ng-to-docx"，三步照它的正文走：按最小集写 `.md`（写在 `%TEMP%` 里，**工作区里不建任何暂存目录**）、`md2docx.py` 转到临时位置、`gate.py --deliver 文书/<节点标题>/<标题>-v{n}.docx` 通过才落盘。版本号 `{n}` 是这个节点算上这一版的生成条目数。

门禁不通过就按不通过项改稿重转重检，**至多 2 次**；仍不通过就是**生成失败**：不落盘、不追加条目、不写审查报告，把门禁输出原文交给律师，告诉他可以兜底自写。永远不要为了过门禁调阈值、跳过门禁、或把临时件手动拷进 `文书/`。

落盘后把稿子拷成同名 `.md`、按 skill "loo0ng-to-docx" 的 `references/审查报告.md` 写 `-审查报告.md`，三件同目录。

### 7. 追加生成条目

```
python <loo0ng-graph 的 scripts/graph.py> --domain <领域目录> generate --node <节点标题> \
    --doc 文书/<节点标题>/<标题>-v{n}.docx --source 文书/<节点标题>/<标题>-v{n}.md \
    --review 文书/<节点标题>/<标题>-v{n}-审查报告.md
```

三件都落了才追加条目：条目里的相对路径是文书的身份，指着不存在的文件就是坏账。

## 生成不问缺事实

材料里没有的案号、日期、金额照出，缺项列进审查报告的「待律师裁定」，**生成中途不停下来问**（ADR-0008）。律师读了报告在对话里答一句：

1. 先落成陈述（调用 skill "loo0ng-filing" 的 `statement.py`，`--reply` 指向那份审查报告），回显一行。**不在盘上的事实不是材料**（ADR-0013）：审查报告的依据必须可引，下一个对话看不到这一句。
2. 再据此重出一版，仍在同一个回合、同一个对话里；新版有它自己的审查报告。

律师对某个问题作的选择（先办哪个、按哪种口径写）是 `性质: 裁定` 的陈述，不是图里的条目。

## 收尾三段

每次回答都以这三段结束，与别的入口同形（ADR-0008）：

1. **落了什么**：文书与审查报告的相对路径、图里追加了什么条目、归档搬了几件、落了几条陈述。
2. **你现在该拍板什么**：审查报告的要点（存疑点、待律师裁定项逐条），请律师读过报告再拍板。
3. **下一句该打什么**：出一版与兜底登记之后固定两行：

   > 本节点在本对话里拍板：说一句「确认 <节点标题>」或「<节点标题> 不适用」。
   > 下一个节点开新对话：`loo0ng-doit 出一版 <下一个节点标题>`。

   拍板之后这个对话就结束了，收尾只说下一个节点开新对话；不知道下一个办什么就打 `ask-loo0ng`。

## 与邻居的边界

- 图的唯一写入口是 skill "loo0ng-graph"：本 skill 不直接改 `图.json`，引擎拒写就照实转告，不自己修 JSON。
- 归档搬运与律师陈述落档归 skill "loo0ng-filing"；转换器、门禁与审查报告格式归 skill "loo0ng-to-docx"；官方模板原件与领域目录归 skill "loo0ng-domain"；起手归 skill "loo0ng-setup-case"，本 skill 不建工作区。
- 律师问「我在哪、下一步做什么」是 skill "ask-loo0ng"，它只读、不写图。
- 本 skill 不含领域语义：换一个领域，这套步骤一字不改。
