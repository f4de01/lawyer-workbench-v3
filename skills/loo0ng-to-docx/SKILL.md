# 出件与门禁

模型写 Markdown，冻结的转换器以官方模板为版式载体转成 DOCX，版式门禁真实渲染检查，通过才一次性落进工作区（ADR-0006）。本 skill 持两个 CLI，互不 import：

- `scripts/md2docx.py`：转换器，只依赖 python-docx，离线。
- `scripts/gate.py`：门禁，只依赖 PyMuPDF 与 powershell.exe（Word COM 出 PDF），只读、可单独对任意 DOCX 跑。

两个都用系统的 `python`（装有 python-docx 与 PyMuPDF）；`uv run python` 是另一套没有这两个库的解释器，不用。`--help` 是参数的权威。

## 出一版的三步

1. **写稿**：按 [references/最小集.md](references/最小集.md) 写 `.md`，先整读该节点的官方模板（`模板/官方/<文件名>`）照它的段落与表格结构写；模板里的 `XX`、`【…】`、「（注：…）」是占位与说明，一个都不能留在稿里。一切标注、疑问、待确认写进审查报告，文书本体只有可提交的正文。
2. **转换到临时位置**：

   ```
   python <本目录>/scripts/md2docx.py <稿.md> --template 模板/官方/<文件名>.docx
   ```

   **不给 `--out`**，它写到 `%TEMP%/loo0ng-to-docx/` 并打印路径；稿子 `.md` 也先写在那个临时目录里。**工作区里不建任何暂存目录**（`_staging/`、`tmp/`、`草稿/` 之类都不要）：工作区里只有过了门禁的东西。退出码 1 是稿子不在最小集里或表形与模板不合，按 stderr 改稿重转。
3. **门禁并落盘**：

   ```
   python <本目录>/scripts/gate.py <临时 docx> --template 模板/官方/<文件名>.docx --deliver 文书/<节点标题>/<标题>-v<n>.docx
   ```

   通过才拷到 `--deliver` 的路径（已存在则拒绝、不覆盖），不通过什么都不落。退出码 0 通过并已落盘、1 不通过或落盘被拒、2 门禁无法运行。

不通过就按不通过项改稿，重转重检**至多 2 次**；仍不通过就是**生成失败**：把门禁输出原文交给律师，不交出不合格件，律师可兜底自写（ADR-0006）。永远不要为了过门禁改成品 DOCX、跳过门禁、或把临时件手动拷进 `文书/`。

门禁的输出（结论、不通过项、披露项）原样贴进审查报告的「版式门禁」段；报告的五段与引用律师陈述的格式见 [references/审查报告.md](references/审查报告.md)。落盘后再把稿子拷成同名的 `.md`、写 `-审查报告.md`，三件同目录；生成条目调用 skill "loo0ng-graph" 追加。

## 门禁查什么

不通过项（客观几何与结构，任一命中即不通过）：行高超阈值、页数超阈值（长标记撑列）；空白页（只有页码的页也算）；表宽超页面；页脚 PAGE 域写死，给了 `--template` 还查丢失；表格直接接 sectPr；元数据残留作者 / 最后修改者 / 上次打印时间；模板占位残留（`XX`、`×××`、`【…】`、下划线串），给了 `--template` 还查模板里括号说明段整段残留。

披露项（写进审查报告，不判不通过）：空单元格坐标（印模、签字等纸质要件本来就空，由律师判断）；请求字体不在嵌入字体里（本机没有方正小标宋简体，Word 用微软雅黑渲出，官方模板自身亦然）；页数；有字没渲出来（多半是模板的固定行高把长文字裁掉了，改短或列进待裁定）。

阈值 `--max-pages`（默认 30）、`--max-row-height`（默认 200 磅）**由律师定，模型不调**：默认值就是门禁，为了过门禁调高阈值与跳过门禁是同一件事；律师说本案文书就是长，落成一条陈述再带参数。一件门禁约 7 秒（Word 冷启动），在 Codex 的 30 秒 shell 上限内。不做姓名词表。

## 没有渲染后端

门禁退出码 2、stderr 「门禁无法运行：无渲染后端」时**不出件、不降级为只做静态检查**，原话转告律师。已知的三种情形：

- 这台机器没有 Word：只能生成失败，律师兜底自写。
- 在 Codex 的沙箱里：沙箱里起不来 Word COM（0x80070520 登录会话不存在），`python` 也不在沙箱的 PATH 上。请求在沙箱外重跑这一条门禁命令，律师批准一次即可；不要改用 `uv run python`。
- Word 瞬时故障：门禁自己整个重试一次，仍不成就报出，再跑一次门禁即可，不要同时跑两件门禁。

## 律师兜底自写的文书

律师说「X 我自己写好了」时，对那份 DOCX 跑一次门禁（不带 `--deliver`），结论与两类项照样写进审查报告，**只披露不阻断**：文件已在 `文书/` 里，不搬、不改、不重转（ADR-0002）。登记为已生成、来源律师，调用 skill "loo0ng-graph" 的 `generate --lawyer-written`。

## 与邻居的边界

- 本 skill 不决定写什么：材料、指南、模板、过往文书、现行陈述的整读与稿子的内容由 skill "loo0ng-doit" 负责；缺的事实照出并列进审查报告的待律师裁定，不停下来问。
- 官方模板原件住领域目录，起手时拷进 `模板/官方/`（skill "loo0ng-domain"、skill "loo0ng-setup-case"）；本 skill 只读它。
- 确定性规则只从真实事故进入：一次事故 → 通用裁定台账 → 一条规则加一对 fixture（仓库 `tests/loo0ng-to-docx/`），不预写。
