# 请这样做（三步，大约十五分钟）

这个包是来测你这台 Mac 的：工作台的 skill 装不装得上、Word 能不能被自动驱动出 PDF。**它不碰你的任何案件文件**，跑完只产出一个结果压缩包。

## 一、解压

把压缩包解到桌面（或任何你找得到的地方）。里面有个文件夹，比如 `mac-20260907`。

## 二、在这个文件夹里开一个 Codex 会话

打开「终端」，把下面这行里的路径换成你刚才解压出来的那个文件夹，回车：

```
cd ~/Desktop/mac-20260907
```

然后打：

```
codex
```

## 三、跟它说一句话

会话开起来之后，打这一句发出去：

```
按这个目录里的 AGENTS.md，从第 1 步做到第 7 步。
```

剩下的它自己走。**中间它会找你两次**：

- 一次让你在 Codex 里打一个 `$`，把补全列表里的名字念给它
- 一次让你守着屏幕点一个授权框（「想要控制 Microsoft Word」那种），点「好」

跑完它会告诉你产出了一个 `实测结果-日期.zip`，在同一个文件夹里。**把那个 zip 发回来就行。**

---

## 几个可能遇到的情况

**它说某一步失败了** —— 不用管，让它继续。这次就是来看哪些能跑哪些不能的，失败本身就是要的结果。

**它问你 GitHub 密码或者要你去弄什么令牌** —— 别给，直接跟它说「跳过这一步，记成拉不下来」。

**Word 自己弹出来、开了两个文档** —— 正常，是脚本在驱动它。别去点关闭，等脚本自己收尾。其中第二份文档有可能把 Word 弄崩，**这也在预料之内**，崩了就崩了，告诉它一声继续。

**它想去看你的案件文件夹** —— 这不该发生。真发生了就打断它，跟它说「AGENTS.md 里第 1 条边界，只在这个包的目录里读写」。
