# 请这样做

这个包是来测你这台 Mac 的：工作台的 skill 装不装得上、Word 能不能被自动驱动出 PDF。**它不碰你的任何案件文件**，跑完只产出一个结果压缩包。

**你不用敲任何命令。** 除了下面这两步开个头，剩下全是 Codex 干活，你只需要点两下、回答一次。

## 一、解压

把压缩包解到桌面。会出来一个文件夹，叫 `mac-20260907`。

## 二、在这个文件夹里开 Codex

打开「终端」，打 `cd ` （**cd 后面留一个空格**），然后**把那个文件夹直接拖进终端窗口**，路径会自己填上。回车。

再打：

```
codex
```

## 三、跟它说一句话

```
按这个目录里的 AGENTS.md，从第 1 步做到第 7 步。
```

发出去，剩下它自己走。

---

## 中途它会找你三次

| 什么时候 | 你要做什么 |
|---|---|
| 它要跑 Word 那一步 | 它会请求一次执行批准，点同意 |
| 紧接着系统弹框 | 「想要控制 Microsoft Word」之类，点「好」，顺便把弹框原话告诉它 |
| 最后一步 | 它让你在输入框里打一个 `$`，把跳出来的名字念给它；然后打完整一个名字加「你好」发出去 |

跑完它会说产出了一个 `实测结果-日期.zip`，就在同一个文件夹里。**把那个 zip 发回来就完事了。**

---

## 可能遇到的情况

**它说某一步失败了**：不用管，让它继续。这次就是来看哪些能跑哪些不能的，**失败本身就是要的结果**。

**它问你 GitHub 密码，或者让你去弄什么令牌**：别给，也别去弄。直接跟它说「跳过，记成拉不下来」。这一条本来就允许失败。

**它让你自己去终端敲命令**：不用听。跟它说「AGENTS.md 里写了所有命令都由你跑，我不进终端」。

**Word 自己弹出来、开了两个文档**：正常，是脚本在驱动它。别去点关闭，等它自己收尾。其中第二份有可能把 Word 弄崩，**这也在预料之内**，崩了就崩了，告诉它一声继续。

**最后一步发出去之后，它好像换了个话题**：正常，说明 `$` 那个名字触发了别的东西。结果压缩包在这之前就已经做好了，不受影响。

**它想去看你的案件文件夹**：这不该发生。真发生了就打断它，跟它说「AGENTS.md 里第 1 条边界，只在这个包的目录里读写」。
