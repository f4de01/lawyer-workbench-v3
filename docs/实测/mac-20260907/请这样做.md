# 请这样做

> **这是第二轮。** 上一轮的包有几个我们自己的毛病，把要测的东西挡住了，已经修好。
> 麻烦你照下面再跑一遍，步骤和上次一样。

这个包是来测你这台 Mac 的：工作台的 skill 装不装得上、WPS 能不能被自动驱动出 PDF。**它不碰你的任何案件文件**，跑完只产出一个结果压缩包。

**你不用敲任何命令。** 除了下面开个头，剩下全是 Codex 干活，你只需要点几下、回答两次。

## 一、解压

把压缩包解到**桌面**。会出来一个文件夹，叫 `mac-20260907`。

解到桌面，别放到「文稿」或 iCloud 里，后面找结果方便。

## 二、在 Codex 里把这个文件夹打开成一个项目

打开 Codex 客户端，让它在 `mac-20260907` 这个文件夹里工作。

不同版本的入口叫法不太一样，找这几个之一就对了：

- 左上角的项目 / 文件夹选择器，选「打开文件夹」「添加项目」之类
- 或者直接把 `mac-20260907` 文件夹**拖进 Codex 窗口**

**认准一件事**：开始之前，Codex 界面上显示的当前项目要是 `mac-20260907`。是这个就对了。

> 如果它说这个文件夹不是 Git 仓库、问你要不要初始化：**同意**，让它初始化就行。

## 三、跟它说一句话

新开一个对话，把下面这句发给它：

```
按这个目录里的 AGENTS.md，从第 1 步做到第 8 步。你自己跑命令，不要让我进终端。
```

发出去，剩下它自己走。

## 中途它会找你四次

| 什么时候 | 你要做什么 |
|---|---|
| 它要跑命令 | 会弹执行批准，点同意 |
| 跑到出 PDF 那一步 | 再批准一次；紧接着系统会弹「想要控制 WPS」之类的授权框，点「好」，**顺便把弹框原话告诉它** |
| 它问你 Skills 侧边栏里有什么 | 打开 Codex 的 **Skills 侧边栏**，把里面看到的名字**逐字念给它**（长什么样念什么样，别替它补全） |
| 最后一步 | 它让你在输入框打一个 `$`，把跳出来的名字念给它；然后打完整一个名字加「你好」发出去 |

跑完它会说产出了一个 `实测结果-日期.zip`，**在你的桌面上**。把那个 zip 发回来就完事了。

### 这三件事它要是没问你，请你主动说

上一轮它把这三问跳过了，说「读不到界面」。它本来就不该去读界面，是该问你。**它要是跑完了还没问，你主动把这三件事告诉它**：

1. 打开 Codex 左边的 **Skills 侧边栏**，里面有没有 `loo0ng` 开头的几项？有的话**一个字一个字念给它**，包括冒号前面的部分（比如是 `loo0ng-doit` 还是 `什么什么:loo0ng-doit`）
2. 在输入框里打一个 `$`（**先别发送**），跳出来的列表里有哪些名字？同样逐字念给它，念完把 `$` 删掉
3. 然后打完整一个名字、后面加「你好」，发出去，看它有什么反应

**这三问是这趟最要紧的产出**，我们要靠它写出你以后每天要打的那一串。

> 结果为什么在桌面不在那个文件夹里：Codex 有时会把任务放进一个它自己的临时副本目录里干活，写在那儿的文件你不好找。所以让它一律把结果放桌面。

## 可能遇到的情况

**它说某一步失败了**：不用管，让它继续。这次就是来看哪些能跑哪些不能的，**失败本身就是要的结果**。

**它问你 GitHub 密码，或者让你去弄什么令牌**：别给，也别去弄。直接跟它说「跳过，记成拉不下来」。这一条本来就允许失败。

**它让你自己去终端敲命令**：不用听。跟它说「AGENTS.md 里写了所有命令都由你跑，我不进终端」。

**它说找不到 `codex` 这个命令**：正常，你这台机器上只有 Codex 客户端、没有命令行版。跟它说「这台机器没有 codex CLI，按 AGENTS.md 记成没有，继续」。

**WPS 自己弹出来、开了两个文档**：正常，是脚本在驱动它。别去点关闭，等它自己收尾。其中第二份有可能把它弄崩，**这也在预料之内**，崩了就崩了，告诉它一声继续。

**它说驱动不了 WPS、或者说 WPS 不支持自动化**：这正是我们要知道的答案之一，让它如实记下来继续，别帮它想办法。

**最后一步发出去之后，它好像换了个话题**：正常，说明 `$` 那个名字触发了别的东西。结果压缩包在这之前就已经做好了，不受影响。

**它想去看你的案件文件夹**：这不该发生。真发生了就打断它，跟它说「AGENTS.md 里第 1 条边界，只在这个包的目录里读写」。
