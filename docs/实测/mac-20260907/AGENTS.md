# 给 Codex：这个目录是一次性的机器实测包

你现在在一个实测包里。任务是把这台 Mac 上的几件事**跑一遍、如实记下来**，然后把结果打包。对应开发仓库的两张票：#40（skill 包在 macOS + Codex 上的安装链与 `$` 提及形态）与 #41（macOS 上 Word 渲染通道的探路）。

**这台机器上只有 Codex 客户端，没有 codex CLI。** 所以任何 `codex ...` 子命令在这里都不存在，不要试、不要装、不要让律师去装。"模型看见了什么"这一问改由两个来源对账：脚本从磁盘抄 `SKILL.md` 的 `name` 字段，律师从 Skills 侧边栏和 `$` 补全里念给你。

**你的产出只有一样**：一个填好的 `出/结论.md`，加上 `出/` 里的原始回显。跑完把 `出/` 打成 zip 放到**桌面**交回。

## 最重要的一条：所有活都你干

律师**不进终端、不敲任何命令**。每一条命令都由你来跑。他只做四件事，都在跟你对话的过程中完成：

- 在你请求执行批准时点一下同意
- 在系统弹授权框时点一下「好」
- 打开 Skills 侧边栏，把看到的名字念给你
- 在最后一步，按你说的在输入框里打一个 `$`，把看到的念给你

**任何时候都不要让他去开终端、去装什么、去找令牌、去改配置。** 你做不了的事就如实记成「未跑到」，那也是有效结果。

## 另外四条边界

1. **只在这个包的目录里读写**，两个例外：安装那一步往 `~/.agents/` 写是任务的一部分；第 7 步把结果 zip 写到 `~/Desktop/` 是为了律师找得到。除此之外不出这个目录：不要打开、不要列出、不要在任何输出里提到这台机器上的案件目录、客户文件、Documents / iCloud 里的内容。
2. **回传件里不出现绝对路径。** 家目录一律写成 `~`。
3. **只记事实，不下结论。** 每一问只回「是 / 否 / 报错原文」。不要判断「这条路可行」「建议改用某某」：判断归开发者，他手上有你没有的三十份决策记录。**跑失败不是你的错，失败本身就是要收集的事实，如实记下来比让它通过重要得多。**
4. **不要试图补上缺的东西。** 没有 `codex` CLI、没有 `node`、拉不下私有仓库，这些都是要收集的事实，不是要解决的障碍。

## 第 0 步　先确认你在哪

客户端有时会把任务放进一个 git worktree，那个目录和律师看到的文件夹不是同一个。先跑：

```bash
pwd && ls && git rev-parse --show-toplevel 2>/dev/null && git rev-parse --git-dir 2>/dev/null
```

把结果原样记进 `出/00-位置.txt`（没有这个文件就新建）。**如果 `pwd` 不是那个 `mac-20260907` 文件夹本身**，在结论的「跑的过程中还注意到的别的事实」里写明白你实际在哪、律师的原目录在哪。

后面每一步都在包的根目录跑（`probe/` 的同级）。

## 第 1 步　脚本换行符

包是从 Windows 打出来的，脚本可能带 `\r`：

```bash
sed -i '' 's/\r$//' probe/*.sh probe/*.applescript 2>/dev/null || perl -pi -e 's/\r$//' probe/*.sh probe/*.applescript
```

## 第 2 步　环境探针（不联网、不起 Word）

```bash
bash probe/01-环境.sh
```

中间某条失败是正常的，不要停，让它跑完。结果在 `出/01-环境.txt`、`02-依赖.txt`、`03-Word.txt`、`06-字典.txt`。

`出/06-字典.txt` 这一份特别值钱：它是从 Word 自己的 AppleScript 字典里搜出来的，**不用起 Word 就能答 #41 的第 2、3 问**。

## 第 3 步　装 skill 包

```bash
bash probe/02-装.sh
```

脚本自带三级兜底，一级不成自动降下一级：网络装 → 本机 `gh` 已登录则克隆后本地装 → 直接拷包里自带的 `skills-兜底/`。

这台机器没有 CLI，多半也没有 `node`，**第 1 级走不通是预期结果**，脚本会记下来并自动降级。第 3 级（直接拷进 `~/.agents/skills/`）对客户端一样有效：客户端和 CLI 读的是同一个目录。

**看 `出/04-安装.txt` 末尾那行 `########  走通的路线：…  ########`，把它原样抄进结论。**

三级都没成也不要紧，如实记。**尤其不要去找 GitHub 令牌、不要让律师去登录**：「私有仓库拉不下来」本身就是 #40 要的答案之一。

## 第 4 步　抄磁盘上的真名

打开 `出/05-清单.txt`，把每件 skill 的 `name` 字段**逐字**抄进结论表，尤其看清**有没有命名空间前缀**（开发机上是 `loo0ng-skills:loo0ng-doit` 这个形状，裸名是 `loo0ng-doit`）。

一个字符都不要改、不要补全、不要「顺手规范化」。

这一步拿到的是**磁盘事实**。模型侧实际看见什么，第 5 步问律师。

## 第 5 步　问律师：Skills 侧边栏里有什么

跟他说：

> 麻烦你打开 Codex 的 Skills 侧边栏（左边栏里找 Skills / 技能），看看列表里有没有 `loo0ng` 开头的几项。有的话，**一字不差地念给我**，包括冒号前面的部分；没有的话就说没有。

他念的**原样**记进结论，不要替他补齐或猜测。他要是说「找不到这个侧边栏」，就照记「未找到 Skills 侧边栏」。

**这一问和第 4 步对账**：磁盘上的 `name` 与侧边栏显示的如果不一致，两个都记下来，不要挑一个。

## 第 6 步　Word 渲染（要一次执行批准 + 一次系统授权）

这一步要驱动 Word，可能会被沙箱拦住。**在沙箱里跑没有意义**：门禁本来就是要在真实渲染下判版式的。

按顺序做：

1. 先跟律师说一句，让他知道待会儿要点什么：

   > 接下来我要让 Word 自动打开两份空白模板、导出 PDF。会有两个地方要你点一下：一个是我这边的执行批准，一个是系统弹的「想要控制 Microsoft Word」授权框，都点同意就行。弹框的原话也告诉我一下。

2. 按你这边的规矩，为下面这一条发起一次**执行批准请求**，并用一句话说明他在批准什么：

   ```bash
   bash probe/03-渲染.sh
   ```

3. 他批准后跑。跑完看 `出/07-渲染.txt`。

**样例 B 是故意挑的**：开发机上这一件在导出时稳定把 Word 弄崩。它崩了不是坏事，把崩的原文原样留在文件里就是这张票要的答案。

如果批准之后仍然被拦，**不要再想别的办法**。在结论的「需要在沙箱外重跑的」一节记上这一条，写清报的是什么，交给开发者。

## 第 7 步　填结论、打包到桌面

把 `出/结论模板.md` 复制成 `出/结论.md`，逐行填。每行只填事实；填不出来的写「未跑到（卡在第 N 步：…）」，**不要留空、也不要编**。

打包**放到桌面**，不要放在当前目录：你可能在一个 worktree 里，写在这儿律师找不到：

```bash
cd 出 && zip -r ~/Desktop/实测结果-$(date +%Y%m%d).zip . && cd ..
ls -la ~/Desktop/实测结果-*.zip
```

（没有 `zip` 就用 `ditto -c -k --sequesterRsrc 出 ~/Desktop/实测结果.zip`。）

确认那个 zip 真的在桌面上了，再告诉律师文件名。

## 第 8 步　最后：请律师试一次 `$`

**放在最后做**，因为试触发有可能打断这个会话；到这一步结果已经打包好了，打断也不影响。

跟他说：

> 最后一件事，麻烦你在下面的输入框里打一个 `$`（先别发送），看看跳出来的补全列表里有哪些名字，逐字念给我，包括冒号前面的部分。念完把 `$` 删掉就行。

记下来之后再说第二句：

> 好，现在麻烦你打完整一个名字，后面加「你好」，发出去。看它有没有反应，有的话是什么反应。

两问的答复**原样**记进结论。他要是说「没看到列表」，就照记「无补全」。

如果发出去之后这个会话被别的 skill 接管了，不要紧：zip 已经在第 7 步放到桌面了。告诉律师：把桌面上那个 zip 发回给开发者就完事了。
