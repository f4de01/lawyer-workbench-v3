# 给 Codex：这个目录是一次性的机器实测包

你现在在一个实测包里。任务是把这台 Mac 上的几件事**跑一遍、如实记下来**，然后把结果打包。对应开发仓库的两张票：#40（skill 包在 macOS + Codex 上的安装链与 `$` 提及形态）与 #41（macOS 上 Word 渲染通道的探路）。

**你的产出只有一样：一个填好的 `出/结论.md`，加上 `出/` 里的原始回显。** 跑完把 `出/` 打成一个 zip 交回。

## 三条边界，比任务本身重要

1. **只在这个包的目录里读写。** 不要打开、不要列出、不要在任何输出里提到这台机器上的案件目录、客户文件、Documents / Desktop / iCloud 里的内容。安装器往它自己的目标目录（`~/.agents/`、`~/.codex/` 之类）写东西是任务的一部分，允许；除此之外不出这个目录。
2. **回传件里不出现绝对路径。** 家目录一律写成 `~`。你自己写的每一行都照这个来。
3. **只记事实，不下结论。** 每一问只回「是 / 否 / 报错原文」。不要判断「这条路可行」「建议改用某某」——判断归开发者，他手上有你没有的三十份决策记录。跑失败不是你的错，失败本身就是要收集的事实，**如实记下来比让它通过重要得多**。

另外：某条命令若因为沙箱受限而失败，**如实记下报错就行，不要想办法绕过**；把它在结论里标一句「需在沙箱外重跑」，留给开发者。

## 按这个顺序做

### 第 1 步　脚本换行符

包是从 Windows 打出来的，脚本可能带 `\r`。先跑一次：

```bash
sed -i '' 's/\r$//' probe/*.sh probe/*.applescript 2>/dev/null || true
```

（没报错就往下走；报了 `Invalid command` 就换成 `perl -pi -e 's/\r$//' probe/*.sh probe/*.applescript`。）

### 第 2 步　第一批探针（不需要人）

```bash
bash probe/01-无人值守.sh
```

它自己会把结果写进 `出/01-环境.txt` 到 `出/06-字典.txt`。**中间某条失败是正常的，不要停，让它跑完。**

### 第 3 步　看一眼安装那步的结果

打开 `出/04-安装.txt`。三种情况：

- **装成功了** → 直接进第 4 步。
- **它停在一个交互提问上，或者 180 秒超时了** → 把那段提问原样抄进 `出/结论.md` 的对应行，然后请律师在**终端里**手动跑一次这条命令、按提示选完，再把终端里的回显整段贴给你，你原样存进 `出/04-安装.txt` 末尾。
- **报的是凭据 / 权限问题（私有仓库拉不下来）** → 原样记下报错，**不要尝试任何绕过办法**，也不要去找 token。这一条记成「未通过：凭据」就够了，它本身就是票 #40 要的答案之一。

### 第 4 步　清单

打开 `出/05-清单.txt`。把里面出现的 skill 名字**逐字**抄进结论表 —— 尤其要看清**有没有命名空间前缀**（开发机上是 `loo0ng-skills:loo0ng-doit` 这个形状，裸名是 `loo0ng-doit`）。一个字符都不要改、不要补全、不要「顺手规范化」。这一串抄错，开发者那边整张入口表就是错的。

### 第 5 步　⚠️ 要请律师动手：TUI 里试一次 `$`

这一步你替不了 —— `codex exec` 里 `$名` 不解析，只有 TUI 里能试。

请律师做，你把回答收进结论：

> 麻烦你开一个新的 Codex 会话（就是平常那样直接开），在输入框打一个 `$`，然后告诉我两件事：
> 1. 补全列表里出现了哪些名字？（逐字念给我，包括冒号前面的部分）
> 2. 挑其中一个打完整，后面加「你好」，发出去。它有反应吗？

拿到答复原样记进结论，**不要替他补齐或猜测**。他要是说「没看到列表」，那就照记「无补全」。

### 第 6 步　⚠️ 要请律师在场：Word 渲染

第一次用脚本驱动 Word，macOS 会弹一个授权框，脚本自己点不了。

先说一句：

> 接下来我要让 Word 自动打开两份空白模板、导出 PDF。屏幕上可能弹一个「终端 想要控制 Microsoft Word」之类的授权框，麻烦你点「好」。弹框的原话也告诉我一下。

他确认在电脑前之后：

```bash
bash probe/02-渲染.sh
```

跑完看 `出/07-渲染.txt`。**样例 B 是故意挑的**：开发机上这一件在导出时稳定把 Word 弄崩。它崩了不是坏事，把崩的原文原样留在文件里就是这张票要的答案。

### 第 7 步　填结论、打包

把 `出/结论模板.md` 复制成 `出/结论.md`，逐行填。每一行只填事实。填不出来的写「未跑到」并说明卡在哪一步，**不要留空、也不要编**。

然后：

```bash
cd 出 && zip -r ../实测结果-$(date +%Y%m%d).zip . && cd ..
```

（没有 `zip` 就用 `ditto -c -k --sequesterRsrc 出 实测结果.zip`。）

告诉律师：把这个 zip 发回给开发者就完事了。
