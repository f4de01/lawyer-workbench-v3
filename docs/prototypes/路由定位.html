原型：路由的定位机制 一次性原型 · 不是产品代码

要回答的问题：路由只读一张案件图（案件图里没有的按「领域」名去领域图找），能不能只靠数组顺序 + 条目推出的状态就回答「当前节点、上一完成、下一任务」三问？回答完之后，「帮助编排提示词」应该以什么形式给出，律师拿到就能用？

怎么玩：左边是案件图，按钮就是律师会发起的动作（生成 / 确认 / 不适用 / 加节点）。右边是路由，输入一句话或点常用问法，看它怎么答。每次动作后路由自动重答。下方「带着走」是几段准备好的情形，专挑纸上想不清的地方。

原型里先假定的几件事（都是待你反应的点，不是已定）：

  • 节点从领域图带入案件图时沿用领域图里的 id；律师自己加的节点拿新 id。路由靠 id 对应两张图，标题改了也不丢。
  • 「当前节点」= 状态为已生成、等律师确认的节点，可以不止一个；一个都没有就是「没有待确认的文书」。
  • 「上一完成」= 现在仍处于已确认状态的节点里，确认时间最晚的那个。已确认后重出的节点不再算「完成」。
  • 「下一任务」先列确认（案件图里所有已生成的），再列生成一个节点：案件图里未生成的优先（那是律师自己加的），其次领域图里案件图还没有的。领域图里挑哪一个有两种策略，右上角可切换。
  • 模块级不适用 = 把该模块在领域图里的全部节点带进案件图、逐个记不适用。图仍是唯一台账，路由不需要模块级标记。
  • 编排 skill 的名字（/生成、/确认 之类）是占位，由「编排层与参考层的 skill 清单」票定；这里只定路由输出的形状。
