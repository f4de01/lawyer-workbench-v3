# 案件工作区固定六格，材料不登记不去重，归档是参考层的自动能力，雏形从案件级指南长出，既有案件不迁移

2.0 的案件目录规范有 7 个材料子目录、8 张登记文件、SHA-256 归档记录与指纹去重，清点显示在办案里归档记录行数与文件数已明显不符；ADR-0002/0003 又废掉了五张表、`已批准/`、`审查报告/`、`快照/`。legal-skills 的 J4（目录规范写 YAML 预设）、J6（迁移处置表）、J8（工作区显式发现）在此一并裁定。我们决定：

- **工作区就是会话当前目录**，`图.json` 是身份标记；找不到就拒绝并提示，初始化是唯一例外（它在当前目录建工作区）。路径参数与环境变量只给开发侧测试用，律师面对的用法只有"在案件目录里开会话"。工作区之上有没有容器层不作规定。
- **目录固定六格**，不写 YAML 预设（J4 不采：只有一个领域、目录只有六个、本机无 PyYAML）：

  ```
  <案件工作区>/
  ├── 图.json            ← 图（ADR-0003）
  ├── 图视图.md          ← 派生视图
  ├── 收件箱/            ← 律师拷入文件的唯一入口，归档后移出
  ├── 材料/              ← 本案事实来源原件；内部只规定 律师陈述/ 一个子目录
  │   └── 律师陈述/
  ├── 指南/              ← 本案适用的官方要求文件
  ├── 模板/官方/  模板/生成/   ← 案件级空白模板，按来源分两格
  └── 文书/<节点标题>/   ← 每版 docx + Markdown 源 + 审查报告
  ```

  不设 `既有文书/`、`已批准/`、`未分类/`、案件元数据文件。案号、法院、当事人的权威来源是材料，材料里没有的由律师陈述给出。
- **材料不登记、不算指纹、不去重、不分类子目录**。归档只把收件箱内的相对路径原样搬到去向格下，目录名文件名一字不改；同名已存在则不搬、留在收件箱并报出。压缩包与照片原样归材料，不解压不识图。
- **归档是参考层的自动能力**。语义判断归模型（本案事实→材料；本案适用的官方要求→指南；官方发布的空白件→模板/官方；自己做的空白件→模板/生成；三格都无正向证据→留在收件箱），搬运归零依赖脚本（不覆盖、不越界在代码里，不靠提示词）。三个进入点：初始化末尾、生成开场、律师一句话；律师不逐件参与。归档只搬不写图，与写入引擎是两个脚本、互不 import。
- **对话里引入的文件落进工作区**。生成时律师指的材料复制进 `材料/`；其他案件的成品文书不整份复制（那会把 A 案内容带进 B 案），剔除案件内容后作为空白模板进 `模板/生成/`。
- **文书一节点一目录**，`文书/<节点标题>/<标题>-v{n}.docx` 与同名 `.md`（模型写的 Markdown 源）、`-审查报告.md`；目录名用节点标题，条目里的相对路径才是身份，改标题不改目录。确认不复制文件。
- **雏形与起手图正交**。起手图三选一（ADR-0004）不改；归档之后若 `指南/` 非空，agent 只读案件级指南，提出图里没有的模块与节点（按标题判重，相似不同名的列出让律师定），回显清单，律师一句"照这个建"后写入。agent 未经律师一句话不写雏形，"惰性只约束 agent"由此不破。同一机制在开发会话里对通用指引手册跑，产出领域图。
- **既有案件不迁移**（J6 只剩一行）。回放案、两个在办案、三个完结案、8 个 `.doc` 原样不动，3.0 不读它们的登记表、不写迁移脚本、不重导；在办案件用 3.0 时另起新工作区，从第一份文书起一份份建，旧目录只作律师在对话里引用文书与材料的来源。

## 考虑过的方案

- 保留按来源分的材料子目录 + 归档记录 + 指纹去重：真实使用里已走样，且 agent 整读原文后分类子目录无功能。
- 初始化预处理时 agent 读既有文书并自动登记为已生成、已递交的视同已确认：登记生成必须由律师一句话发起（ADR-0002），确认永不自动；初始化只出建议表。
- 一次性迁移脚本或用初始化重导两个在办案：3.0 的用法是逐节点在对话里引入文书与材料，整批导入不是它的路径。
- 归档做成律师调用的编排 skill：分类是 agent 能力，逐件问律师正是 2.0"反复确认"的形态。
- 从指南长雏形作为第四个起手选项：起手图回答"从哪张图开始"，雏形回答"在这张图上先长什么"，两者独立。
- 其他案件成品整份复制进本案工作区：跨案件带入案件内容。

## 后果

- 律师主循环票收下三条前提：生成开场自动归档并回显；生成时律师指的文件复制进工作区；既有成品的登记是"律师一句话、agent 一条"，一句话可以是"都按建议表登记"。
- skill 清单票定归档、雏形两个能力的归属与名字，以及 8 个 `.doc` 进不进领域目录。
- 律师陈述的落盘格式与审查报告引用方式成为独立票，位置已定为 `材料/律师陈述/`。
- 词汇表新增收件箱、材料、指南、雏形、归档五条，初始化条改写；"既有文书"进入避免用词。
