# 主循环只有三个入口，一回合一对话，图的每类写入只有一条来路，生成不问缺事实

2.0 的流程是从「哪些能力要封成 skill」正推的：6 个律师可调 skill 加 4 个动作脚本、每个再分出示与落盘两段，试用结论是命令太多、反复确认（handoff §2.1）。ADR-0002 已把律师动作收成生成 / 确认 / 不适用、确认点收成一个。本 ADR 从律师一天的八种事（起手、出一版、按反馈重出或自写兜底、材料到了、记事实与裁定、宣告不适用、改图构成、问路）反推入口与确认点。判据只有一条，取自 Matt 体系 `invocation.md`：**模型能不能有用地自己够到**：能，就是对话里一句话或自动，由参考 skill 落；不能，才是律师打名字的入口。

我们决定：

- **主循环三个入口**：`init` 起手（建六格、起手图三选一、归档、回显起手清单等一句话；前置是没有 `图.json`，一案一次）、`draft` 出一版（一句自由文本点名一个节点，可带「以第 n 版为底」「用某模板或过往文书」「我自己写好了」与补充要求；开场归档、复制律师指的文件、惰性建节点、出件或登记兜底件、回显审查报告要点）、`decide` 拍板（自由文本「确认 X」或「X 不适用」或「模块 Y 不适用」，落一条回显；已确认的不能不适用，引擎拒）。路由是可选独立件（ADR-0005），存档归图存档票。入口名与显示名归 skill 清单票。
- **确认与不适用必须是入口，不是句子**。它们是仅有的两项律师专权，ADR-0002 要求保护落在代码里而不是提示词里；harness 的 user-invoked 门（Claude Code 硬拦、Codex 软门）是提示词之外唯一能拦住模型的位置。合成一个入口而不是两个：动词始终在自由文本里（ADR-0005），少一个要记的名字。
- **图的每类写入只有一条来路**：生成条目 ← `draft`（含兜底登记），确认与不适用条目 ← `decide`，构成改动与律师陈述 ← 律师一句话经参考 skill，条目不可改 ← 引擎。「一个事实只在一处存」延伸为「一类写入只有一条来路」。
- **确认点**：每份文书一次（读审查报告后 `decide`）、案件起手最多一次（起手清单 = 雏形 + 既有成品建议登记，合成一张、一句话）。其余为零：归档自动、陈述与改图一句话即落、缺事实不问。
- **一回合一对话，入口强制**。回合 = 一个节点从 `draft` 到拍板，含审查报告不通过时的重出；之后再改是新回合、新对话。同一对话里 `draft` 第二次指向另一节点即拒绝并指向开新对话；同一节点重出不拒；`decide` 不限，隔夜确认必须允许。同出的一批文书是几个回合、几个对话，每个都重读材料，这是接受的代价。引擎看不见对话边界，强制只能落在入口自身。
- **生成不问缺事实**。材料里没有的案号、日期、金额照出，缺项列进审查报告「待律师裁定」，律师答一句成律师陈述再重出。唯一例外：某节点材料、空白模板、律师陈述三样全无时，`draft` 只回缺什么、不出件，不算一次生成失败。
- **入口收尾同形**：落了什么 → 你现在该拍板什么 → 下一句该打什么（入口名 + 一句自由文本，要不要开新对话），与路由同一段话。`draft` 收尾固定两行：本节点在本对话里拍板；下一节点开新对话。
- **2.0 四项发起权的去向**：批准 → `decide` 确认；节点标记 → 不存在，状态由条目推出；分支适用 → `decide` 不适用；律师陈述 → 一句话进 `材料/律师陈述/`。

## 考虑过的方案

- 两个入口，确认与不适用做成对话里一句话：律师专权退回提示词保护，legal-skills 的教训是长会话里不可靠。
- 四个入口，确认与不适用各一个：一动作一入口，律师在路由票里已裁「大部分功能会合在一起做」。
- 确认收进 `draft` 对话末尾的一句话：同上退回提示词，且隔夜确认要重开出件对话。
- `init` 并进 `draft`，无图时先建工作区：起手图三选一是人的决定（ADR-0004），不该藏进出件对话。
- 兜底登记独立为一句话：生成条目多一条来路。
- 一个对话顺序出同出的一批节点，「一节点一对话」只作卫生建议：省下重读材料，但 smart zone 是硬约束，律师裁定必须强制。
- 生成中停下来问缺的事实，或出件前先列缺项等补齐：都是把确认点塞回生成中间，正是 2.0 的反复确认。

## 后果

- skill 清单票收下：三个入口的定义与自由文本形态、入口名只能 `a-z 0-9 -`、参考 skill 须是 model-invoked 并把「律师说了事实 / 要改图 / 要归档」写进触发描述；路由原型里「指向加节点的入口」改为指向 `draft`。
- 律师陈述票收下：陈述由一句话触发、agent 落文件回显，不设入口、不设确认；生成缺事实时的「律师答一句」也走这条路。
- 图存档票收下：存档是否为第四个入口由它定；决策树第五问「都没有 → 存档」的落点在那里。
- 每个节点重读材料的成本随材料体量线性增长；出现一次「材料大到读不完」的真实事故再议缓存或摘要。
- `CONTEXT.md` 新增「回合」「起手清单」，改「初始化」「编排 skill」「参考 skill」。

## 附注（2026-09-09，ADR-0019）

确认点清单加一条：**每份文书确认之后，若该节点在领域图里没有，多一次归属拍板**（模块与去案件化标题，agent 给默认值，律师一句话）。它不违本 ADR "确认点收到最少"的立场，理由有二：它是**有条件的**，只在领域图缺这个节点时出现；它**自带衰减**，领域图越完整问得越少，一个领域走熟之后趋近于零。律师侧 2026-09-09 明确接受这个代价。其余确认点一条不变，"生成不问缺事实"不变。
