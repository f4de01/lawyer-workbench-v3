# 时限是领域图节点上的一句话属性，案件层不写、不拷贝、按 id 查出，截止日只在审查报告里推算，路由不因期限改序

ADR-0003 定图不存案件元数据，把「期限是否进图」留在迷雾里，等律师主循环与律师陈述的形态定下再看；两者已由 ADR-0008 / ADR-0010 与 ADR-0013 定下。2.0 素材（`knowledge/流程模型/破产.md`）里期限是逐节点一行「法定期限」：固定、与个案无关的轻提示，不顺延节假日，出处分「法律规定 / 法院要求」两类；大半节点是「及时」或「无明示期限」，有天数的几乎全是相对期限，基准事件只有五六种（收到指定决定书日、裁定受理日、一债会召开日、程序终结日、最后分配公告日）。通用裁定台账首行（一债会资料报送 3 日 / 5 日两源不一致，两条分别登记、实务从严）是两源冲突的真实样例。

我们决定：

- **时限是领域图节点上一个可选的一句话属性。** 一句去案件化的原文，如「自收到指定管理人决定书之日起 3 日内（手册，法院要求）」，不结构化、不算日期；两源冲突照台账裁定在同一句里把两条都写出。它是定义层的东西，所以归领域图，是节点属性而不是模块属性——素材里它就逐节点存在。
- **只记管理人自己在该节点上要守的期限。** 文书必须告知他人的期限（债权人 15 日内提起确认之诉、分配公告后 2 个月不领视为放弃）是文书内容的要求，属于指引原文，生成时 agent 直接读、写进文书正文与审查报告，不进图。
- **只记有天数的与只有锚点的，「及时」与「无明示期限」不记。** 「第一次债权人会议召开前完成」是可核对的顺序事实（图里看得出一债会开了没开）；「及时」什么都核对不了，写上只是噪音，属性缺省。
- **案件图不存、不拷贝、不改写。** 节点从领域图带入案件图时标题拷贝（律师可改）而时限不拷贝，派生视图与前方按 id 到领域图里查出原样带出，与「来源」同一条查法；案件图格式因此完全不变。律师自加节点与从案件级指南长出的雏形节点在案件图里没有时限：其规则若通用，回流时由开发者在领域图上写上这句话（ADR-0012 回的是图的构成，这句话属于构成）；若不通用，它是案件事实，走律师陈述。
- **基准日与具体截止日是案件事实，图不存。** 基准日只认材料与律师陈述，永不用条目时间——条目时间是拍板时刻，不是法律事件发生日。法院指定的具体日期（如债权申报截止日）只作律师陈述或材料存在，案件图节点不覆盖时限；派生视图与前方上看到的永远是相对规则，不是本案的具体日期，这一点已明知并接受。
- **截止日在审查报告里推算，作为披露项。** 审查报告固定一段「时限」：写出规则、基准日及其出处（哪份材料或哪条陈述、标性质档）、算出的日期，三样并列让律师一眼能复核；不顺延节假日（顺延规则因法院而异，算了反而误导）；节点没时限时一行「无明示时限」。基准日缺失照 ADR-0008 列「待律师裁定」，律师答一句落成陈述再重出。版式门禁不检查这一项，它不是版式事故。
- **路由不因期限改序。** 五问有序决策树不变（ADR-0005、票「路由的定位机制」）；路由只读图与领域图，不读材料与陈述，算不出真正的截止日，任何「临近」判断都是猜。路由在「往下的路」里把那句话原样附上，判断留给律师。

## 考虑过的方案

- 完全不进图，时限只留在指引手册原文里由 agent 生成时读：审查报告仍能推算，但路由与前方对时限一无所知，律师看整条路时得不到素材本来就逐节点给出的那行轻提示。
- 结构化规则（基准事件 + 天数 + 出处性质）进领域图、引擎能算：要为一个六成节点填不出来的字段设计模式，「基准事件」枚举会把破产语义写进图格式，而基准日本来就不在图里，引擎算不成。
- 时限作为模块属性：素材里逐节点，同一模块内各节点的期限互不相同。
- 带入案件图时拷贝时限：领域图改了句子，已带入的案件图不跟，制造过期副本；案件层本来不写时限。
- 案件图节点允许律师覆盖为本案具体日期：图开始存事实，与 ADR-0003「案件元数据不进图」相悖；具体日期走陈述，审查报告引它时自然带性质档。
- 路由加一问「有临近期限的先做」：路由不读材料，只能猜；ADR-0005 路由不猜。
- 也记「及时」：不可核对，只增噪音。
- 用条目时间当基准日：确认时间与法律事件日常差好几天，算出的截止日是错的。

## 后果

- `CONTEXT.md` 新增「时限」；「领域图」「派生视图」「审查报告」三条各加一句。
- ADR-0003 后果里「期限暂留迷雾」由本 ADR 取代；ADR-0004「图里没有要件、没有出处指针」不变，时限那句话里的出处性质是句子的一部分，不是可跳转的指针，附注说明。
- 领域图节点多一个可选属性，`格式版本` 随之升；字段名与精确 JSON 形状在 `loo0ng-graph` 实现票里定。案件图的格式不变。
- 雏形机制在开发会话对通用指引手册跑时，连时限那句话一起提出；回流带这句话。
- 审查报告多一个固定段「时限」；路由回复的「往下的路」附时限句子；版式门禁无变化。
- 「时限」属性在破产以外的领域可以整个缺省，图格式不因它带入任何领域语义。
