# 图存档是派生视图的机器可读形态，没有存档时点，前方随视图出，引擎不出任何呈现物

制图时「图存档」被定义为"趋近完整的图被保存下来的版本，供路由参考，并为可视化提供数据"，本票要定"趋近完整"的判据、存档时点与对可视化插件暴露什么。到本票时两个用途已经各失其一：ADR-0005 定了路由直接读案件图、按名字读领域图，不读任何存档；ADR-0004 定了"趋近完整的图被保存下来"就是领域图（剔除条目、去案件化），而"什么时候值得回流"是反哺票的问题。剩下的只有"给可视化提供数据"。调研票（#11）查到 MCP App 消费一个 JSON（`structuredContent`）加一段模型可读文本（`content`），且 Claude Code 与 Codex 两个 CLI 都还不渲染，落盘文件是唯一可见通道。

我们决定：

- **图存档改义为派生视图的机器可读形态**。它是引擎每次写图之后覆盖重算的一份文件 `图视图.json`，与律师读的 `图视图.md` 同基名、同一条重算规则、同放工作区根（ADR-0007 的「图与视图」一格）。它不是另存的快照：没有"趋近完整"的判据，没有存档时点。判据问题整个移交反哺票，改问"何时值得回流"。
- **暴露算好的全量**。顶层：`格式版本`、`领域`、`生成时间`、`源图`（`图.json` 的相对路径）、模块列表、前方。模块：标题、顺序、算好的模块状态（只有三个值：不适用、已完成、进行中；规则住引擎）。节点：标题、顺序、空白模板属性、算好的状态、文书版本序列（每版 docx / Markdown 源 / 审查报告的相对路径）、每条条目原文（含律师那句话与时间）。案件名、案号等元数据一概不进：派生视图不承载图里没有的事实（ADR-0003）。
- **前方随视图出**。领域图里有、案件图里还没有的模块与节点，由引擎按 id 对应算出来，作为独立一段列在视图里，形状与图里的模块/节点一致，多一个 `来源: 领域图` 标记，状态为"尚未进图"；一个模块整体没进图就整个模块列在前方。图本身仍严格惰性：惰性约束的是写入（ADR-0004），前方是读出。
- **两份 JSON 都带 `格式版本`**。`图.json` 与 `图视图.json` 同一个整数、同步升；插件遇到不认识的版本明确报错，不猜。与版式门禁"没有渲染能力时明确报错，不降级"同一种态度。
- **引擎不出任何呈现物**。不出 HTML、不加"读视图"CLI 子命令、不设 MCP server。`图视图.json` 就是将来 MCP App 的 `structuredContent`，`图视图.md` 就是它的 `content`；可视化插件读 `图视图.json` 出 HTML 落盘，那就是调研说的"不能删的出口"。插件在另一张图里。
- **领域目录保持三样**。引擎只为案件图出派生视图；开发者要看领域图，在测试工作区用"整份领域图"起手（ADR-0004 起手三选一），看那个工作区的视图。
- **接口按工作区各一份**。跨案件汇总是把多个工作区的 `图视图.json` 读在一起，归可视化插件那张图；路由与视图都不跨工作区。

## 考虑过的方案

- 保留原义，定"趋近完整"的判据与时点、另存一份：没有任何消费者需要那个时点，条目本来就带时间，历史已在图里；判据会与反哺票各存一份。
- 派生文件只是 `图.json` 的原样拷贝、插件自己推状态：状态推算规则只能住引擎（ADR-0003），第二份规则迟早走样。
- 只给节点与状态、不带条目与路径：插件没法显示律师那句话与时间线，而 ADR-0010 要求视图显示它。
- 前方不带、插件自己读领域图：插件要复刻路由已经在做的"按 id 对应"。
- 引擎顺手出 HTML 或加读视图的 CLI：只有一个假想的消费者；两份文件已经正好对应 MCP 的两个槽位。
- 领域目录允许多两个派生文件：为它松动"只有三样"没有换来任何起手三选一给不了的东西。
- 路由跨案件回答：路由要离开当前目录去找别的工作区，而"工作区之上怎么摆不作规定"（ADR-0007）让它没有可靠的找法。

## 后果

- `CONTEXT.md`：「图存档」「派生视图」「可视化插件」三条改写；新增「前方」。
- ADR-0003 后果里"是否同时出 HTML 由图存档票定"的答案是不出；ADR-0009 里"图存档各留一槽"的槽关闭：图存档是 `loo0ng-graph` 引擎的一个输出，不是独立 skill（它没有律师一句话就该被模型够到的场景）。
- 反哺票「案件图反哺领域图」接手"何时值得回流"，本票不再阻塞它。
- 地图雾里"多案件并行时路由与图存档的关系"移入 Out of scope。
- 字段的精确 JSON 形状在 `loo0ng-graph` 的实现票里定，本 ADR 只定暴露什么、不暴露什么。
