开发者造或维护一个领域，从头到尾一条路走通（#103，ADR-0020）：`sketch.py home --empty` 起头，`sketch.py intake` 入库收尾，中间那段（办一遍、逐节点回流进活图）走的就是律师那条路，没有另做。

**`home --empty`**：`home` 原先在「活图位置上没有这个领域、包里也没有种子」时拒，而开发者要造一份全新领域的种子，起点恰恰是这里。加 `--empty` 之后它在活图位置建目录、经引擎 `init --kind domain --name <领域名>` 起一份空领域图，回显仍是那一行绝对路径（`活图：<路径>`），下游一个字不用改。包里已经有出厂种子时它拒（不带 `--empty` 再跑一次就是从种子整份拷一份），不给种子盖一份空的。写图仍只经引擎子进程；与拷种子同一个形状，先落临时名再改名，引擎拒了就一格不留。两侧同一条路的意思就是开发侧也享受 ADR-0019 那条低入场费（新领域从空图起手），卡在「活图建不出来」那就不是同一条路。

**`intake`**：把开发者活图那份 `领域图.json` 送进本仓库成为出厂种子。**只拿这一份文件**，不拿整个领域目录（官方模板原件与指引手册原文是原件，走普通的 git 添加；整份拷会把活图目录下的任何东西卷进仓库，正是硬边界 1 最不想要的形状，`AGENTS.md` 结构不变量 5 因此不受影响）。拷之前先经引擎 `validate` 校验（格式合法、无条目，那是读不是写），**再把这次比种子多了什么、改了什么分栏回显**：新增、改名、改属性、改归属、种子里有而活图里没有，各占一栏，头一行数出「多了几个模块几个节点、改了几个标题」。这行分栏是本票的重点：两侧同一条路带来一个原来没有的风险，开发者的活图里混着他试办案子回流进去的东西，入库从「逐条精挑」变成「整份送进去」，第二双眼要审的 diff 一下子变大且没有摘要，这几行是隐私钩子与第二双眼之前的第一道人眼过滤。种子根不在一个 git 工作树里（装好的那份 skill 包）就拒，律师那一侧永不入库；活图里写的领域名与 `--name` 对不上也拒；与种子逐字相同就一个字不拷。子命令不叫 `publish`：入库不是 skill 包的版本发布（ADR-0009「维护即发布」说的是后者），一次包发布可以带零次或多次入库；入库须经第二双眼（硬边界 2），审的就是那段 diff。它是一次拷贝、不经图引擎，所以不受 #99 落下的那条「包内种子谁都不许写」约束，那条拒管的是会话里的每一次写图，照旧立着，入库没有绕过它，只是走的另一条路：一次要人审的 git 提交。这三句正文里写着，免得日后有人以为它绕过了守门。

正文三处跟着改：`loo0ng-domain` 加「入库」一节、活图那节加 `home --empty` 一行、种子那条的「改由入库更新」指向新那一节；`references/回流.md` 开发侧第 1 步加 `--empty`，末尾那节把「还没落地，别去调它」换成真的命令与它的规矩；`CONTEXT.md`「入库」词条补上命令名与「拷之前校验并分栏回显」。断言在 `tests/loo0ng-domain/test_home.py`（新领域从空图起手六条：建目录并起空领域图、回显第一行仍是绝对路径、起出来的图引擎认、包里有种子就拒且不建目录、已有活图就一个字不动、引擎拒了不留半个活图）与新增的 `tests/loo0ng-domain/test_intake.py`（15 条，含本票要的那一条：新增与改名各占一栏、不混在一起，改前改后都写出来）。

**同时修一处正文的洞**（律师 0.1.0 现场报的）：起手时律师只说了「空图，自己一步步长」、没说领域，agent 拿本机上唯一那个「破产」种子当默认起了一张破产领域的空图，律师说「我要做新领域的空图」才纠正。`loo0ng-setup-case` 正文原先把起手图三选一写成「只问这一件」，领域名默认从环境里来，这就是那个洞。改成：要定的是两件（哪一种起手图、这案子是哪个领域），一次问齐；**领域名只能由律师给，不许从本机上有什么推出来**（种子有哪些是安装的事，案子是哪个领域是律师的事）；律师答的是一个此前没有过的领域名，那不是笔误，是「新领域从空图起手」那一行。起手图三选一那张表因此拆成四行，空图分成「这个领域有领域目录」与「全新领域」两种，后者 `--domain-name` 与 `--domain` 都不给、指针块「领域目录」记「无」；收尾第一段那行起手图连领域名一起念。新增 eval 用例「空图没给领域」守它：律师那句话里空图说清了、领域没说，断言图与两份视图没落盘、一格没建、收件箱原封不动、回复里问了领域。Claude Code 侧实测：stash 掉正文这一处改动跑同一条用例就红，回的正是「领域名你没说，我按 `破产` 起的」；改后两侧都绿。
