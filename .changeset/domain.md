新增参考 skill `loo0ng-domain`：领域目录与雏形机制。`assets/破产/` 下领域目录三样就位：19 件官方模板原件（自 `knowledge/模板/` 搬入）、2 份指引手册原文（自 `docs/指引手册/` 搬入）、领域图「破产」的合法空壳（有领域名、无模块，模块与节点由下一票对指引手册跑雏形长出）；既有案件的 `.doc` 不进。`scripts/sketch.py` 零依赖、不 import 图引擎：`check` 按标题判重（归一化后同名的已在图里不重复提出、相似不同名的列为待定、与领域图同名的标为带入）并回显清单、图一字不动；`apply` 在律师一句话拍板后逐条经 skill "loo0ng-graph" 的引擎子进程写入，待定未定即整个拒，案件图上时限句只回显不写；`from-case` 是回流第一步，从案件图算出「领域图没有且至少一版已确认」的模块与节点、保留原 id 写成雏形文件；`docx-text` 把 docx 指南与手册打成纯文本供整读。`references/` 三篇：雏形格式与判重规则、时限句取舍、回流步骤。另交付种子「指南」与用例「出雏形」，`tests/loo0ng-domain/` 用合成小领域跑。
